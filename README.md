# RețeteSmart 🍽️

> Planuri alimentare generate de AI, liste de cumpărături integrate - totul într-o interfață modernă, 2026 style.

![Status](https://img.shields.io/badge/status-MVP-orange)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Funcționalități

### Rețete
- Catalog de rețete cu imagini de înaltă calitate
- Filtrare pe categorii: Mic Dejun, Prânz, Cină, Desert
- Detalii complete: timp de preparare, porții, dificultate, preț estimat
- Modali frumoase cu lista de ingrediente

### Lista de Cumpărături
- ✅ Checkbox-uri cu strike-through când bifezi
- 📊 Progress bar și statistici live
- 🗑️ Ștergere elemente bifate sau toate
- 💾 Salvare în localStorage (persistență)

### Design 2026
- 🌙 Dark/Light mode cu toggle smooth
- 🍊 Culori calde (orange/amber accent)
- ✨ Glassmorphism subtil
- 🎭 Micro-animations pe hover/click
- 📱 Fully responsive

### Monetizare (MVP)
- Plan gratuit: 10 rețete/lună
- Plan Popular: 25 lei/lună - rețete nelimitate + AI
- Plan Pro: 45 lei/lună - comision 0% pe comenzi

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid, Animations
- **Vanilla JavaScript** - ES6+, fără framework
- **Google Fonts** - Inter font family
- **Unsplash** - Imagini royalty-free

> Zero dependencies, zero build step, GitHub Pages ready! 🚀
